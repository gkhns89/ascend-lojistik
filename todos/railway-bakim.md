# Railway bakımı

- **Öncelik:** Düşük
- **Kim:** kullanıcı + kod
- **Boyut:** küçük
- **Kaynak:** hafıza `railway-environment.md`

## Yapılacak

- [ ] `railway.json` yerine Railway'in yeni biçimi (`.railway/railway.ts`).
      Mevcut dosyalar hâlâ okunuyor, acil değil.
- [ ] Panelde "Attached to: N/A" görünen sahipsiz volume kayıtlarını sil.
- [ ] Değişkeni panelden değiştirirken açılan "N changes to apply" listesini
      satır satır oku. CLI ile yazılmış değişkenler bu listede silme olarak
      görünebiliyor (10 Kasım 2026).
